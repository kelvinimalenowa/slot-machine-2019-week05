# 🎰 Lucky Mart Slots

Lucky Mart Slots is a simple, interactive slot machine game built with HTML, CSS, and JavaScript. Players start with a virtual balance, choose between two bet amounts, and spin three randomized reels for a chance to win.

I built this project to practice JavaScript fundamentals including functions, arrays, conditionals, event listeners, DOM manipulation, and generating random values.

[Play Lucky Mart Slots](https://delightful-basbousa-a6013c.netlify.app/)

## ✨ Features

- Start with a $100 virtual balance
- Choose between $5 and $50 bets
- Spin three randomized reels
- Match all three symbols to win
- Automatically update the player's balance after each spin
- Prevent bets when the player's balance is too low
- Responsive design for desktop and mobile devices

## 🎮 How It Works

Players begin with a $100 balance and can choose to bet either $5 or $50.

After placing a bet, Lucky Mart randomly selects three symbols for the reels. The bet is deducted from the player's balance, and if all three symbols match, the player wins five times their bet.

If the player's balance is too low to place the selected bet, the game prompts them to reload their wallet.
